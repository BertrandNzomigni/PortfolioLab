# Projet PortfolioLab

PortfolioLab est une simulation d'une plateforme de courtage. Elle permet :
- d'acheter et de vendre des actions d'entreprises du S&P 500.
- d'accéder aux informations générales du portfolio.
- de suivre les transactions effectuées.

Afin d'utiliser l'application, téléchargez la, ouvrez le terminal dans son répertoire et saisissez `bun run dev`. L'authentification s'effectue avec un compte Google.
